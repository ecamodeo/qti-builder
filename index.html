QTI Builder

Paste a questions payload and download a Schoology-importable QTI v2.1 .zip — all in your browser.

Supported question types & JSON shape

multiple_choice, true_false, multiple_select, matching, ordering, fill_blank_text, fill_blank_dropdown, short_answer, highlight_image. Every question may include an optional feedback object with correct / incorrect messages. Stems support inline HTML via prompt (escaped) or prompt_html (raw, multiple choice). highlight_image gives the student a drawing canvas to show work (teacher-graded); optional width, height, and background ("white" or "grid"). Math: write LaTeX in $…$ (inline) or $$…$$ (display) in any question text — prompts, choices, matching/ordering items, dropdown options, and feedback — it's converted to MathML that Schoology renders. In JSON, double every backslash (\\frac, not \frac); use \$ for a literal dollar sign.

Generates QTI v2.1 packages compatible with Schoology → Resources → Import → QTI. Output matches the reference Python generator byte-for-byte (apart from the random IDs).
